# BALI COCKTAIL v1

Новая ветка развития BALI COCKTAIL.

В этом репозитории находятся:
- мобильное приложение Android;
- мобильное приложение iOS;
- администраторская панель для управления каталогом с компьютера;
- файловый каталог данных без отдельной серверной БД;
- автоматическая синхронизация техкарт и официальных изображений в мобильные приложения.

Старый репозиторий `Nik13599/BALI-COCKTAIL` не изменяется и используется только как источник текущей стабильной мобильной версии.
